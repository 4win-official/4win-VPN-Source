# Offline world country outlines

`world_countries.json` contains simplified country polygons derived from Natural Earth 1:110m Admin 0 Countries. The source dataset is public domain; the GeoJSON conversion used as input is distributed under CC0: https://github.com/nvkelso/natural-earth-vector and https://github.com/martynafford/natural-earth-geojson.

The data was simplified for a low-memory mobile background map. Country codes use Natural Earth's ISO alpha-2 fields; geometry is approximate at this scale.
